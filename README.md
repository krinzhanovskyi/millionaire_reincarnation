# Who Wants to Be a Millionaire V 2.0.0

A simple console game written in PHP.
The game has 15 questions, each with four answer choices.
You earn virtual currency throughout the game.
The game has “checkpoints” that ensure you'll be able to receive your progress.

## Run

Linux
Open a terminal in the project folder and run:

```bash
php millionaire.php
```

Windows
Install the Docker container with the extension on Linux;
this way, you'll be able to use the project on Windows.

Choose an option from the start menu and enter your name. Answer each question
with `A`, `B`, `C`, or `D`. After answering, you can continue playing or take
your current prize.

## Files

- `millionaire.php` - game code
- `questions.json` - questions and answers
- `prizes.json` - prize amounts
- `LICENSE` - MIT license file
